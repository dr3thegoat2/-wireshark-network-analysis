# Wireshark Network Traffic Analysis

## Project Overview
This project demonstrates hands-on packet capture and network security analysis using Wireshark.

## Tools
- Wireshark
- Windows PowerShell
- DNS and TCP/IP

## DNS Analysis
Captured four DNS packets for example.com, including A and AAAA queries and their responses.

### Findings
- Client IP: 10.130.244.162
- DNS server: 1.1.1.1
- Domain: example.com
- Query types: A and AAAA
- Result: Both queries received responses.

## Security Relevance
DNS analysis helps security analysts investigate unusual domain requests and potential malicious communications.
